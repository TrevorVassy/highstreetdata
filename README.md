# High Street Data

Website for High Street Data, the data engineering consulting side of High Street Co. LLC.

Live at https://highstreetdata.com. It's served by GitHub Pages from the `master` branch root.

## Editing

It's a single static page: `index.html` holds the markup, styles and a small menu script. There's no build step. To preview, open `index.html` in a browser. To publish, commit and push to `master`. Pages redeploys in about a minute.

Sister site: [high-street-co](https://github.com/TrevorVassy/high-street-co) (highstreetcollc.com).
